## 🌟 Overview

**AiMaker** is a beautifully designed, completely client-side tool built for the AI Roleplay community. Whether you are generating a brand new persona, editing an existing card, or extracting hidden data from a PNG image, everything is handled cleanly right in your browser.

Supports the **Character Card V2** specification with full compatibility across all major roleplay platforms — plus **KrizRP** integration.

Built with a sleek **light and dark theme** (light by default) so you can craft characters comfortably in any environment.

## 🧩 Core Workspaces

### ✨ Create & Edit
Design new characters from scratch or modify existing ones with a guided, intuitive interface.
- Full set of structural fields: **Description**, **Personality**, **Scenario**, **First Message**, **Message Examples**, and **Alternate Greetings**.
- Advanced fields for power users: **System Prompt**, **Post History Instructions**, **Creator Notes**, and a **Custom Extensions JSON** editor.
- Upload a character image (PNG, JPEG, or WebP) or let AiMaker auto-generate a stylish default avatar.
- Export your character as a `.json` file or embed it seamlessly into a PNG image as a valid TavernAI card.
- Load existing PNG or JSON cards directly into the editor for quick updates.

### 🔍 Decode & Extract
Reveal the hidden data inside any PNG card.
- Upload any TavernAI/Chub PNG card and instantly view all embedded character fields.
- Copy or download the raw JSON extraction with one click.
- Open any decoded card directly in the editor to start modifying it immediately.
