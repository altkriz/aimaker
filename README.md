## 🌟 Overview

**Tavern Card Maker** is a beautifully designed, completely client-side tool built for the AI Roleplay community. Whether you are generating a brand new persona, updating an older card to newer formats, or extracting hidden data from an existing image, everything is handled cleanly right in your browser.

Supports both **Character Card V2** and the latest **Character Card V3** specifications!

## 🧩 Core Workspaces

### ✨ Character Creator
Design new characters from scratch with a guided, intuitive interface.
- Includes advanced structural fields: **System Prompt**, **Creator Notes**, **Post History Instructions**, and **Alternate Greetings**.
- Export your character out as a `.json` file or embed it completely seamlessly into a newly forged PNG image.
- Native format selection between **Chara Card V2** or the new **Chara Card V3**.

### ✏️ Card Editor
Breathe new life into your existing cards.
- Upload an existing Character Card (PNG or JSON) to quickly edit their personality, scenario, or details.
- Seamlessly inject new fields (like V3 formats) or adapt older/barebones cards to ensure wide compatibility. 

### 🔨 Card Forger
The perfect tool for modders and specific use-cases.
- Take a raw JSON file containing character data and embed it forcefully into any PNG image you want, transforming it into a valid Tavern Card.

### 🔍 Data Extractor
Reveal the hidden soul of a PNG card.
- Upload any Tavern/Chub PNG card and instantly view, copy, or download its raw JSON extraction.
